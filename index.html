    0.1 这门学科是干什么的？从一个产品说起

    假设你在一家银行买了一款「挂钩沪深 300 指数」的理财：指数涨你多赚，跌了保本。你拿到的是一张纸，银行拿到的是一个难题——这个产品该定什么价？指数暴涨暴跌时银行自己会不会亏穿？回答这两个问题的人，就是金融工程师（Quant）。

    拆开来看，这类工作永远是三段式：

    1. 拆解：把一个花哨的产品拆成若干个「标准零件」——比如「保本 + 挂钩指数」= 一张存款 + 一份看涨期权。任何复杂产品都能这么拆，这是本学科最重要的思维方式。
    2. 定价：每个标准零件都有成熟的定价方法（本手册第 4–9 章教的就是这些），加总即产品公允价值。
    3. 对冲：银行卖给你一份期权，自己就承担了对应的指数风险，于是要在市场上反向操作把这个风险转移掉（第 7、10 章讲怎么算、怎么对）。

    所以金融工程不是「预测股票涨跌的玄学」，它更像金融世界的土木工程：不预测地震，但保证桥梁在地震中不塌。这门学科研究的是定价与风险管理的方法论，而不是荐股。

    💡 贯穿全书的三个问题学任何一个新概念时，反复问自己：它值多少钱（定价）？风险从哪来（风险分解）？怎么复制或对冲（工程实现）？回答得出这三个问题，才算真的学会了。

    0.3 初学者最常见的六个问题

    Q1：数学不好真的能学吗？
    能。金融工程用到的数学广而不深——真正天天用的是「贴现、期望、方差」这几个朴素概念，而不是高深的证明。本手册的策略是：需要什么数学，就在哪里补什么数学，并且每个公式都配直觉解释和算例。你唯一需要的是不害怕符号的耐心。

    Q2：需要考研 / 名校学历吗？
    取决于目标。想进券商、基金的量化岗，学历门槛确实高（硕士起步是常态）；但学会这套知识本身对投资、风控、产品、数据分析师等工作都有直接价值，自学到能跑通本书全部算例的程度，你已经超过大多数从业者了。

    Q3：多久能入门？
    按附录 A 的标准计划：16 周完成主线、能独立给期权定价并解释希腊字母，就算「入门」；8 个月的从容版更稳。每天 1–1.5 小时是可持续的节奏。

    Q4：CFA / FRM / CQF 有用吗？
    证书是求职信号，不是知识本身。建议：先用本手册打基础，方向确定后再决定考不考——FRM 对应第 10 章风控方向，CFA 对应投资管理，CQF 对应衍生品建模。本末倒置（只刷证书不动手算）是常见的坑。

    Q5：学完能赚钱吗？
    直接回答：知识 ≠ 收益。这套体系教你的是「价格是怎么来的、风险在哪」，它能让你避开大多数低级骗局、看懂产品合同，但不构成任何投资建议。量化赚钱靠的是执行、数据与纪律，那是另一门手艺。

    Q6：直接刷 Hull 教材行不行？

    第 1 章金融工程总览

    前置要求：第 0 章 预计时长：3–4 小时 难度：★☆☆ 配套阅读：Hull 第 1 章
    🎯 本章学习目标能向别人解释金融工程的定义与三大支柱；说清一个真实产品从设计到对冲的完整流程；了解职业方向与后面各章在体系中的位置。

    1.1 什么是金融工程：三个角色比喻

    金融工程（Financial Engineering）是综合运用金融理论、数学工具与计算技术，对金融产品进行设计、定价、风险管理与程序化实现的学科。抽象定义不好记，记住三个比喻：

    • 产品设计师：客户要「跌了保本、涨了跟涨」，普通存款做不到，设计师把它拆成「存款 + 期权」的组合——这是设计。
    • 定价工程师：这个组合今天到底值 97 元还是 103 元？不能拍脑袋，要按无套利原则算出来——这是定价（本手册一半的篇幅都在讲这个）。
    • 风险翻译官：产品卖出去后，银行承担的所有风险要用一组数字（风险指标）翻译出来，并逐一消除或控制在限额内——这是对冲与风控。

    与相邻学科的关系：金融数学偏重随机分析的严格证明；量化投资偏重用统计规律构建交易策略；金融工程居中，强调产品与工程实现——既要懂模型，也要能把它变成可运行的系统。

    1.3 三大支柱：各学什么、学到什么程度

    • 数学支柱：微积分（变化率与近似）、概率统计（不确定性的语言）、随机过程（价格怎么随时间波动）、数值方法（没有解析解怎么办）。程度要求：会用结论、会算例、能解释直觉；不要求会证明。→ 第 2、8、9 章。
    • 金融支柱：市场机制（在哪交易、怎么清算）、产品（股票债券外汇商品及四大衍生品）、无套利定价逻辑、组合与风险理论。程度要求：每个产品能说清「现金流是什么、风险是什么」。→ 第 3–6、10 章。
    • 计算支柱：Python 做原型与回测（必学）、SQL 处理数据（常用）、C++ 做高性能生产系统（入职再学不迟）、QuantLib 等定价库（会用）。→ 第 9 章。
    ⚠️ 初学者常见弯路① 一上来死磕测度论、实分析，三个月没碰过一张期权——顺序反了；② 只看书不动手算，自以为懂了，一算就错；③ 一开始就想做交易策略，结果连远期和期权的区别都说不清。本手册的顺序就是为了避开这三条弯路。

    1.4 一分钟发展简史（帮助建立背景感）

    • 1973：Black、Scholes 发表期权定价公式，同年芝加哥期权交易所（CBOE）开业——「定价有了公式，交易有了场所」，现代衍生品市场从此起步。
    • 1980 年代：利率互换等场外产品兴起，投行 Quant 队伍扩张；「金融工程」成为正式学科。
    • 1990 年代：VaR 成为行业标准风险度量；数学家大规模进入华尔街。
    • 2008：金融危机暴露模型依赖与流动性风险，行业反思「模型不是全部」；场外衍生品被推动集中清算。
    • 2010 年代至今：量化与算法交易普及，机器学习进入因子挖掘与执行优化；国内量化与衍生品市场快速发展。

    1.5 典型工作流（工程师视角）

    1. 问题定义：对冲什么风险？给什么产品定价？赚什么钱？——先把问题说清楚，模型选错方向一切白费。
    2. 假设与建模：选资产价格模型（如几何布朗运动）、明确市场摩擦假设（有没有交易成本、能不能卖空）。
    3. 参数校准：用市场价格反推模型参数（最典型的是隐含波动率）——模型参数不是拍出来的。
    4. 定价 / 回测：解析解、数值方法（树、蒙特卡洛、有限差分）或历史回测。
    5. 风险分析：希腊字母、情景与压力测试。
    6. 对冲或执行：制定动态对冲计划，控制交易成本。
    7. 监控与迭代：模型表现监控、偏差归因、迭代改进。模型上线不是结束，是开始。

    用「三个角色」的话术，向一个外行解释什么是金融工程。
    参考答案：金融工程师是金融世界的「产品设计师 + 估价师 + 风险翻译官」。客户提出一个收益需求，我们把它拆成标准零件（设计），算出每个零件今天值多少钱（定价），再把产品卖出去后自己承担的风险用数字翻译出来并消除掉（对冲）。我们不预测市场涨跌，我们保证「价格是对的、风险是可控的」。
    为什么说「无套利」是金融工程的核心假设？
    因为无套利提供了相对定价的基准：两种未来现金流完全相同的组合，今天必须同价，否则出现「买低卖高」的无风险利润，市场力量会迅速消除它。于是可以由已知价格（股票、债券）推算未知价格（衍生品），而无需预测涨跌。第 6、7 章的定价全部建立在这条逻辑上。
    金融工程、金融数学、量化投资三者的侧重有什么不同？
    金融数学侧重随机分析的理论严谨性（测度、鞅、随机微分方程）；量化投资侧重用统计规律构建可交易的策略；金融工程介于两者之间，强调产品设计与工程实现——把模型变成能定价、能对冲、能上线的完整方案。
    回顾 1.2 节的产品流程表：为什么「校准」被单独列为一步？不做行不行？
    不行。模型里总有市场无法直接观察的参数（尤其是波动率），必须用当前市场价格反推（校准），否则模型价和市场价会对不上，定价和对冲都会失真。校准质量直接决定模型是否「接地气」，这也是第 7 章隐含波动率概念的重要性所在。

    2.1 从复利到 e：金融里最重要的常数

    先想一个问题：10000 元，年利率 5%。一年后拿多少？

    • 一年结一次息：10000 × 1.05 = 10500 元。
    • 每季度结息转存（季度利率 5%/4）：10000 × (1 + 0.05/4)⁴ = 10509.5 元。
    • 每月结息：10000 × (1 + 0.05/12)¹² = 10511.6 元。
    • 连续复利（利息「瞬间」滚存）的极限：10000 × e0.05 = 10512.7 元。
    离散复利：(1 + r/m)mT → 连续复利极限：erTe ≈ 2.71828。结息频率 m 越高，终值越大，但增量越来越小，上限是 erT。
    🧮 算一算：连续复利互换

    银行报价「年利率 5%，连续复利」。等价的年复利（一年结一次）是多少？

    1. 连续复利终值：1 × e0.05 = 1.05127
    2. 设等价年复利 r′：1 + r′ = 1.05127
    3. r′ = 5.127%——连续复利 5% 相当于年复利 5.127%。

    这个换算在债券和衍生品市场天天用，务必亲手算一遍。

    贴现是复利的逆运算：一年后的 105 元，按 5% 连续复利折算今天值 105 × e−0.05 = 99.88 元。整个定价学科的底层动作就一句话：未来的现金流，按无风险利率折回今天。

    2.2 导数与泰勒展开：希腊字母的数学来源

    导数 = 变化率。债券价格 P 随利率 y 变化，那么「利率涨一点，价格跌多少」就是 dP/dy——金融里给它起了专门的名字（久期 / Delta）。而泰勒展开回答的是「变化一大截时怎么办」：

    f(x + Δx) ≈ f(x) + f′(x)·Δx + ½·f″(x)·(Δx)²一阶项 = 线性近似；二阶项 = 修正弯曲程度。定价中：一阶项对应 Delta / 久期，二阶项对应 Gamma / 凸性。
    🧮 算一算：一阶近似的误差从哪来

    f(x) = x²，在 x = 100 处，估计 f(102)。

    1. 真实值：102² = 10404
    2. 一阶近似：100² + 2·100·2 = 10000 + 400 = 10400（差 4）
    3. 二阶近似：再加 ½·2·2² = 4 → 10404，完全命中

    结论：变化小时一阶够用；变化大时必须加二阶项——这就是后面「凸性修正」「Gamma 对冲」存在的原因。

    2.3 概率论：不确定性的语言

    期望是「加权平均」（权重是概率），直觉上是分布的重心；方差衡量「偏离重心的程度」，是分散程度；标准差是方差的平方根，与原值同量纲——金融里我们管它叫波动率。

    正态分布（钟形曲线）是概率论的主角，记住「68–95–99.7 法则」：取值落在均值 ±1 倍标准差内的概率约 68%，±2 倍约 95%，±3 倍约 99.7%。风险管理里说的「3σ 事件」就是指这之外的罕见情形。

    ⚠️ 为什么股价用对数正态，不用正态？正态分布可以取负值，而股价不能为负。解决办法：假设收益率的对数（即 ln S）服从正态，则 S 服从对数正态——永远为正，且右偏（大涨可以很大）。另外记住换算关系：价格波动率按 √T 放大（方差按 T 放大），「1 年波动 20%」意味着 4 年大约波动 40%。
    若 ln ST ~ N(m, s²)，则 E[ST] = em + s²/2对数正态均值比「直接取指数」多出 s²/2——这就是 BS 公式里 (r − σ²/2)T 项的来源之一，也解释了为什么「波动率本身有价值」。

    条件期望 E[X|Y]：「已知 Y 的信息后 X 的平均」。塔式法则 E[X] = E[E[X|Y]] 允许「先分组平均、再总平均」，蒙特卡洛方差缩减（第 9 章）就是靠它。

    🧮 算一算：分散化的威力（手算组合波动率）

    组合 A 资产占 60%（波动率 20%），B 资产占 40%（波动率 10%），两者相关系数 ρ = 0.3。求组合波动率。

    1. 公式：σp² = w₁²σ₁² + w₂²σ₂² + 2·w₁w₂·ρ·σ₁σ₂
    2. 代入：0.36×0.04 + 0.16×0.01 + 2×0.6×0.4×0.3×0.2×0.1
    3. = 0.0144 + 0.0016 + 0.00288 = 0.01888
    4. σp = √0.01888 ≈ 13.7%

    对比：若按「加权平均波动率」 naive 计算 = 0.6×20% + 0.4×10% = 16%。13.7% < 16%，少的 2.3 个百分点就是分散化收益——只要两项资产不是完全同涨同跌（ρ < 1），组合波动率必然低于加权平均。这是第 5 章的种子。

    2.4 统计推断常识：参数都是估出来的

    金融模型的输入（均值、波动率、相关系数）都来自历史数据的估计，而估计有误差。三个必须建立的常识：

    • 样本均值极不稳定：用 20 年数据估年化收益，标准误可能和估计值一样大——所以「预测收益」远比「预测波动率」不可靠，业界干脆用无套利绕开它（第 3.4 节）。
    • 金融数据三大恶习：肥尾（极端行情比正态假设频繁得多）、波动聚集（大波动跟大波动）、相关性不稳定（平时 0.3，危机时 0.8）。任何模型结果都要拿这三条照镜子。
    • 相关 ≠ 因果：回测里的规律可能是巧合或数据挖掘（第 10 章详谈）。

    2.5 随机过程入门：价格是怎么「随机」的

    随机过程 = 随时间演化的随机变量序列。想象一个醉汉每分钟随机走一步，走很多步后的位置就是一个随机过程。把步长无限细分、步频无限加快，就得到金融建模的基石——

    布朗运动 Wt（维纳过程），四个性质：

    • 从 W₀ = 0 出发；
    • 路径连续（但处处不光滑——放大看永远是锯齿）；
    • 独立增量：不相交时间段的变化互不影响（过去的走势不含未来信息，对应弱式有效市场）；
    • 增量服从正态：Wt+Δt − Wt ~ N(0, Δt)，方差与时间间隔成正比。

    股票价格不能为负也不能恒为 0，所以在布朗运动外面套一层：让漂移和波动都与当前价格成正比，得到几何布朗运动（GBM）——期权定价的标准模型：

    dSt = μ·St·dt + σ·St·dWtμ 为期望漂移（年化），σ 为波动率。含义：价格每单位时间平均涨 μS，同时叠加大小为 σS 的随机扰动。

    这个方程的解（第 9 章蒙特卡洛直接用它）：

    ST = S0·exp[ (μ − σ²/2)·T + σ·√T·Z ]， Z ~ N(0,1)注意 −σ²/2 这一项：它保证了 E[S_T] = S₀e^{μT}。直觉：波动本身会「拖累」复合增长（涨 50% 再跌 33% 才回到原点）。

    但价格是随机变量，普通微积分的链式法则对它不成立，需要修正版——伊藤引理：

    df = ( ∂f/∂t + μ·S·∂f/∂S + ½·σ²·S²·∂²f/∂S² )·dt + σ·S·(∂f/∂S)·dW比普通链式法则多出 ½·σ²·S²·f″。原因：布朗路径太粗糙，(dW)² 的量级不是零而是 dt（二次变差，第 8 章细讲）。
    🧮 算一算：第一次使用伊藤引理

    设 S 服从 GBM（漂移 μ、波动率 σ），求 f(S) = S² 的动力学。

    1. 普通链式法则：df = f′(S)·dS = 2S·dS
    2. 伊藤修正：加 ½·f″(S)·σ²S²·dt = ½·2·σ²S²·dt = σ²S²·dt
    3. 合并：d(S²) = 2S·(μS·dt + σS·dW) + σ²S²·dt
    4. d(S²) = (2μ + σ²)·S²·dt + 2σ·S²·dW

    看：多出来的 (2μ+σ²) 而不是 2μ，正是 ½ 项的贡献。初学阶段你只需要会这种「三步替换」：写普通导数 → 加 ½σ²S²f″ 项 → 合并整理。

    💡 本阶段要求伊藤引理会用即可，不要求会证。测度、鞅这些词先混个眼熟，第 8 章会补齐原理。卡住了就先往后学定价，回头再消化——这是正常的学习曲线。

    年利率 6%（连续复利），2 年后的 10000 元今天的现值是多少？
    PV = 10000 × e−0.06×2 = 10000 × e−0.12 ≈ 10000 × 0.8869 ≈ 8869 元。贴现就是乘 e−rT，务必练到不用想。
    为什么股价建模用对数正态而不用正态？
    正态分布可取负值，而股价（有限责任）不能为负；对数正态把 ln S 设为正态，保证 S > 0，且右偏特征与长期股价经验分布更吻合。相应地，价格波动率按 √T 放大（方差按 T 放大）。
    伊藤引理比普通链式法则多出的那一项是什么？为什么会出现？
    多出 ½·σ²·S²·∂²f/∂S²。因为布朗运动路径极不规则，其二次变差 (dW)² 的量级是 dt 而非零，泰勒展开的二阶项不能像确定性微积分那样忽略。这也是「波动率本身有价值」的数学根源。
    σ=20% 的资产，1 年和 4 年的「1 倍标准差」对数波动分别约多少？
    分别约 20% 和 40%：波动率随 √T 放大（√4 = 2）。方差才与时间成正比。这是初学者最常犯的 √T / T 混淆，务必记住。
    两资产完全正相关（ρ=1）时，组合波动率是多少？完全负相关（ρ=−1）呢？
    ρ=1 时 σp = w₁σ₁ + w₂σ₂（加权平均，无分散化收益）；ρ=−1 时 σp = |w₁σ₁ − w₂σ₂|（可完全对冲至 0，选择权重使 w₁σ₁ = w₂σ₂ 即可）。一般情形介于两者之间——分散化收益来自「不完全相关」。

    第 3 章金融市场与产品基础

    前置要求：第 1 章 预计时长：6–8 小时 难度：★☆☆ 配套阅读：Hull 第 1–2 章
    🎯 本章学习目标了解市场怎么运转（在哪交易、谁参与、怎么清算）；能区分远期、期货、期权、掉期并说明各自用途；深刻理解无套利与复制——这是后面所有定价章的发动机。

    3.1 市场是怎么运转的

    一级市场是「发行」：公司第一次卖股票（IPO）、政府发国债，钱从投资者流向融资方。二级市场是「转手」：投资者之间买卖已发行的证券，它提供流动性——正因为随时能卖掉，人们才愿意买。

    按组织方式分两种：

    • 交易所市场：标准化合约集中在同一场所（或电子系统）撮合，价格公开透明。中央对手方清算：交易所的清算所「插」在买卖双方中间——你买入的合约，对手其实是清算所，卖方违约也轮不到你承担，风险被集中管理。这是交易所安全的来源。
    • 场外市场（OTC）：双方私下签定制合约（金额、期限随需求定），灵活但要自己承担对手方违约风险。2008 年金融危机后，标准化的场外衍生品也被逐步推进集中清算。

    主要玩家：做市商（同时挂买卖价、提供流动性赚价差）、套利者（纠正错误定价）、对冲者（转移已有风险）、投机者（主动承担风险换预期收益）、资管机构（代理客户投资）。四类需求互相成就：没有投机者提供对手盘，对冲者的风险就没人接。

    3.2 基础资产四件套

    • 股票：公司的所有权份额。收益 = 股价变动 + 分红。风险来自经营与市场情绪，定价理论见第 5 章。
    • 债券：一张标准的「欠条」：约定票息、到期日、面值。主要风险是利率（第 4 章）与信用（对方还不起）。市场规模比股票大得多，是一切定价的「利率基准」来源。
    • 外汇：一种货币的「价格」是另一种货币。利率平价把两国利率和远期汇率连起来（与第 6 章持有成本同构）。
    • 商品：黄金、原油、铜、大豆……特殊之处：有存储成本（要租仓库、付保险），也有便利收益（手里有货的隐性好处：工厂随时能开工）。这两个概念在第 6 章定价时登场。

    指数（如沪深 300、标普 500）不是资产，是一篮子资产的加权价格——但它可以作为期货和期权的标的，是衍生品市场最活跃的品种。

    3.3 衍生品四大家族：用生活例子入门

    ① 远期（Forward）——「先说好，到期一手交钱一手交货」。

    面馆每月要用 100 袋面粉。农民担心麦价跌，面馆担心麦价涨。两人今天签约：「3 个月后，面馆按每袋 100 元向农民买 100 袋。」到期无论市价多少，都按 100 元成交。双方都睡得着觉了——这就是对冲。远期合约是双边的、定制的、私下签的，所以有对手方违约风险（到期时麦价大跌，农民可能耍赖不交货）。

    ② 期货（Futures）——「标准化 + 交易所担保的远期」。

    把上面那张私人合约搬到交易所：数量、质量、交割地点全部标准化，每天逐日盯市（盈亏当天结算），双方各交保证金给清算所，谁违约就扣谁的保证金。违约风险几乎消失，合约还能随时转手。代价：失去了定制自由。

    ③ 期权（Option）——「买一个权利，而不是义务」。

    看涨期权：付 5 元权利金，获得「3 个月后有权按 100 元买入」——到时候市价 120，你就行权赚 15（120−100−5）；市价 80，你不行权，只亏 5 元权利金。最大亏损锁定，收益上限打开——盈亏不对称，这正是它与远期期货的本质区别（后两者盈亏对称，涨多少赚多少也跌多少亏多少）。它像一份保险：付保费，买保障，理赔看行情。

    ④ 掉期（Swap）——「交换现金流」。

    最常见的是利率互换：A 公司能借到便宜的固定利率贷款但想要浮动，B 恰好相反，于是两家通过银行互换「你替我付浮动、我替你付固定」，各自拿到想要的利率形式，还都省了钱（比较优势原理）。利率互换 = 一串远期的组合，是场外市场成交量最大的品种。

    💡 用途三分法任何一笔衍生品交易的动机都逃不出：对冲（转移已有风险）、投机（主动承担风险）、套利（赚定价错误的钱）。分析任何产品先问：谁在对冲、谁在投机、套利空间在哪。

    3.4 无套利与复制：定价的发动机

    一价定律：同样的东西不能同时有两个价。苹果在 A 市场卖 5 元、B 市场卖 7 元？搬运工立刻从 A 买、往 B 卖，来回搬运直到价差被运费抹平。套利就是金融版的搬运：零投入（或自融资）、零风险、正收益。无套利假设说的是：市场足够有效，搬运工（套利者）会瞬间抹平一切免费午餐。

    这给我们一个强大的定价套路——复制：

    1. 用市场上已有价格的东西（股票、债券、其他衍生品）构造一个组合；
    2. 让它在未来任何情形下的现金流都和目标产品完全一样；
    3. 那么目标产品的价格 = 这个组合的构造成本。完事，不需要预测涨跌。
    🧮 算一算：一个迷你套利检查

    无风险利率 5%（连续复利）。某资产现货 100 元，市场上同时有人愿意按「1 年后 106 元」和你成交远期（远期价格 106）。有没有套利？

    1. 理论远期价：F = 100 × e0.05 = 105.13
    2. 市场远期价 106 > 105.13 → 远期被高估，套利：借 100 买现货 + 按 106 卖出远期
    3. 一年后：交出现货收 106，还贷款 100×e0.05 = 105.13
    4. 无风险利润 = 106 − 105.13 = 0.87 元（每 100 元本金，杠杆下可观）

    真实市场中这种偏差会被机器在毫秒内吃掉——所以正常情况下远期价格就「钉」在 105 附近。记住这个套路：比较「合成出来的价格」和「市场价格」，偏差即套利，定价公式即由「令偏差为零」推出。第 6、7 章全部使用这个套路。

    💡 相对定价 vs 绝对定价无套利定价是相对定价：给定股票和国债的价格，回答期权应该值多少——不回答「股票会不会涨」。预测期望收益（绝对定价）是资产配置与策略研究的事（第 5、10 章）。两条线分工明确，初学者最容易混。

    3.5 交易成本：真实世界的摩擦力

    看一眼盘口：买一价 10.00（你挂卖单能立即成交的价），卖一价 10.02（你挂买单能立即成交的价）。这 0.02 就是买卖价差——如果你买了立刻卖，瞬间亏 0.02（约 0.2%）。再加上滑点（大单会把价格推向不利方向）、佣金、保证金占用。很多回测里赚钱的策略，扣掉成本就死了——第 10 章回测部分会反复强调。期权做市商的生死线，就是 Gamma 对冲成本与买卖价差之和。

    3.6 破除三个常见误解

    • 「衍生品 = 赌博」：工具本身无善恶。面馆和农民用远期锁定成本与销路，航空公司用期权锁定油价——没有衍生品，实体经济反而暴露在更大波动中。出问题的是脱离对冲需求的过度投机。
    • 「保证金交易一定会爆仓」：爆仓源于杠杆使用不当，不是期货本身。理解保证金与盯市机制（第 6 章）后，风险是可计算、可控制的。
    • 「期权买方必亏（权利金白扔）」：单次大概率亏权利金，但买期权买的是「尾部保护 + 非线性收益」，价值要看组合与情境。保险也是「大概率白交保费」的生意，但没人说保险是骗局。

    第 4 章固定收益证券

    前置要求：2.1–2.2 预计时长：8–10 小时 难度：★★☆ 配套阅读：Hull 第 4 章
    🎯 本章学习目标会一步步给债券定价；理解 YTM、即期与远期利率、期限结构；熟练计算久期与凸性并用它们估计价格变化；理解利率互换的经济含义与定价思路。本章算例最多，请务必拿纸笔跟着算。

    4.1 现值思维：一切定价的地基

    「今天的一块钱比明年的一块钱值钱」——因为今天的钱可以存起来吃利息。把未来的钱换算成今天的价值，就叫贴现，用的比率就是贴现率（可以理解为资金的机会成本）。金融工程 90% 的定价动作，最终都归结为：列出未来所有现金流 → 每一笔贴现 → 加总。

    4.2 债券定价：完整算例走一遍

    债券 = 一串约定的现金流：期间付票息 C，到期还面值 F。给定贴现率（到期收益率 y），价格就是全部现金流的现值：

    P = ∑t CFt / (1+y)t 附息券速算：P = C·[1 − (1+y)−n]/y + F·(1+y)−n
    🧮 算一算：给一只 3 年期债券定价

    面值 100 元，票息率 5%（每年付一次），剩余期限 3 年，市场要求的收益率 y = 6%。值多少钱？

    1. 列出现金流：t=1 付 5；t=2 付 5；t=3 付 105
    2. 逐笔贴现：5/1.06 = 4.717；5/1.06² = 4.450；105/1.06³ = 88.161
    3. 加总：P = 97.33 元

    注意两点：① 价格低于面值（97.33 < 100），因为市场要 6% 而票息只有 5%，价格必须「让利」补足收益；② y 越高价格越低——价格与收益率反向变动，这是固定收益的第一定律。请自行重算 y = 7% 的情形（应得约 94.75），体会这一定律。

    到期收益率（YTM）就是反过来问：「按市价 97.33 买入并持有到期，年化收益是多少？」——即使 P 与现金流相等的那个 y。它是债券市场的通用报价语言。

    4.3 期限结构：即期利率与远期利率

    上面用一个 y 贴现所有现金流是简化。更严谨的做法是：不同期限用不同的贴现率——1 年期资金一个价、2 年期一个价……这条「利率 vs 期限」的曲线就是期限结构（收益率曲线）。

    • 即期利率 s(t)：从今天到 t 的零息（一次还本付息）年化利率。零息债券没有再投资风险，是构建曲线的原料。
    • 远期利率 f(t₁,t₂)：今天就能锁定的「未来 t₁ 到 t₂ 区间利率」。它由即期利率无套利推出：把钱存 2 年，应该等价于存 1 年 + 到时续存 1 年（远期锁定）。
    (1+s₂)² = (1+s₁)·(1+f)， 即 f = (1+s₂)²/(1+s₁) − 1
    🧮 算一算：从即期曲线剥出远期利率

    s₁ = 4%（1 年期），s₂ = 4.5%（2 年期）。市场隐含的「明年借一年的利率」是多少？

    1. (1.045)² = 1.092025；(1.04) = 1.04
    2. f = 1.092025 / 1.04 − 1 = 0.05002
    3. f ≈ 5.0%

    解读：曲线越陡，隐含的未来利率越高。曲线通常向上倾斜（长端补偿不确定性）；倒挂（短端 > 长端）常被解读为市场预期央行将降息、经济走弱——历史上多次先于衰退出现。

    4.4 久期：价格对利率有多敏感

    直觉版本：久期 = 收回债券现金流的「加权平均等待时间」（权重 = 各笔现金流的现值占比）。零息债券 3 年期 → 所有钱 3 年后到 → 久期就是 3 年；附息债券因为期间有票息回流，久期短于期限。

    工程版本（真正常用的）：久期衡量利率小幅变动时价格变多少。

    Dmac = (1/P)·∑ t·PV(CFt)， Dmod = Dmac/(1+y)， ΔP/P ≈ −Dmod·Δy + ½·C·(Δy)²麦考利久期 = 加权平均时间；修正久期 = 价格对利率的弹性；C = 凸性，修正大幅变动。
    🧮 算一算：久期与凸性的完整计算（用 4.2 的债券）

    面值 100、票息 5%、3 年期、y = 6%，P = 97.33（前面已算）。求久期、凸性，并估计收益率升到 7% 后的价格。

    1. 各笔现金流现值占比：t=1：4.717/97.33 = 4.85%；t=2：4.450/97.33 = 4.57%；t=3：88.161/97.33 = 90.58%
    2. 麦考利久期：D = 1×0.0485 + 2×0.0457 + 3×0.9058 = 2.86 年
    3. 修正久期：D* = 2.86/1.06 = 2.70
    4. 凸性：C = (1/P)·∑ t(t+1)·CFt/(1+y)t+2 ≈ 10.0
    5. Δy = +1% 线性近似：ΔP ≈ −2.70 × 97.33 × 0.01 = −2.63 → P ≈ 94.71
    6. 加凸性修正：+ ½ × 10.0 × (0.01)² × 97.33 = +0.05 → P ≈ 94.76
    7. 真实值（y=7% 重新贴现）：94.75 ✓——只差 1 分钱

    体会：线性近似在小幅变动时够用（0.5% 变动误差不到 1 分钱）；变动越大（1%+），凸性修正越必要。凸性永远是正的贡献：利率跌时涨得更多、涨时跌得更少——所以凸性大的债券更贵，市场早就给它定过价了。

    ⚠️ 易错点① 久期是一阶近似，大幅波动必须加凸性；② 零息债券久期 = 期限（没有中途现金流）；③ Dmac 单位是「年」，Dmod 是「每单位利率变化的价格弹性」，别混用；④ 久期只度量平行移动，曲线变陡变扁需要关键利率久期（进阶）。

    4.5 免疫：久期的实战用法

    养老金 10 年后要付 1 亿：买入久期 = 10 年、现值 = 1 亿贴现值的债券组合。利率升降时，资产与负债价值同向变动、一阶抵消，净头寸对利率「免疫」。由于久期随时间与利率变化，需要定期再平衡。这是保险公司与养老金资产负债管理（ALM）的看家本领，也是「久期匹配」四个字的全部含义。

    4.6 利率互换：交换比较优势

    场景：A 公司信用好，固定、浮动利率贷款都比 B 便宜，但固定利率优势更大（相对优势）。A 想要浮动、B 想要固定 → 通过银行互换：A 付浮动收固定，B 反之，两家都比直接借钱省。这就是利率互换的经济本质：交换比较优势。

    定价视角（第 3 章的复制思想再用一次）：付固定收浮动的互换 = 「发行固定利率债券 + 买入浮动利率票据」。浮动端在每次重置日的价值回到面值，所以定价核心全在固定端的贴现——而贴现因子来自 4.3 的即期曲线。互换利率 = 使互换初始价值为零的固定票息率，它本身就是市场基准利率曲线（如 IRS 曲线）的来源。

    • 久期 = 现金流加权平均时间 = 利率敏感度；凸性修正二阶误差，永远为正贡献。

    第 5 章投资组合理论

    前置要求：2.3–2.4 预计时长：6–8 小时 难度：★★☆ 配套阅读：博迪《投资学》组合部分（选读）
    🎯 本章学习目标会计算组合的收益与风险（手算两资产）；理解有效前沿与分散化；掌握 CAPM 与 β 的直觉与用法；理解多因子模型能回答什么问题；知道风险度量各有取舍。

    5.1 先统一度量衡：收益与风险怎么算

    收益：年化收益率。注意算术平均与几何平均的区别——先涨 50% 再跌 50%，算术平均 0%，实际亏 25%（几何平均为负）。评估长期业绩永远看几何 / 年化复合。风险：收益率的标准差（波动率），用历史数据估计（日波动率 × √252 转年化，√252 ≈ 15.87，这个数字会在你职业生涯出现一万次）。

    5.2 均值-方差框架：科学地「放鸡蛋」

    Markowitz（1952，诺奖）的贡献是把「不要把鸡蛋放一个篮子」变成可计算的优化问题。输入：各资产的期望收益 μ 和协方差矩阵 Σ。输出：给定风险下收益最高的权重 w。

    Rp = wTμ， σp² = wTΣw = ∑i,j wi·wj·σij组合风险取决于协方差而非单个方差——分散化的数学本质。

    第 2 章已经手算过两资产组合（13.7% < 加权平均 16%）。把它推广：资产数量越多、两两相关性越低，组合波动率相对加权平均被削得越狠。极端演示：N 个完全独立、波动率相同的资产等权组合，波动率 = 单资产 / √N——分散化是免费的午餐（CAPM 说唯一不能分散掉的是市场本身，见 5.4）。

    有效前沿：把「每个收益水平下方差最小的组合」连成曲线。它向右上方弯曲——想要更高收益必须承担更多风险，但曲线下方的所有组合都是「不划算」的（同样的风险能拿到更高收益）。前沿最左端的顶点叫全局最小方差组合。

    5.3 引入无风险资产：一条线改变一切

    把部分钱放国债（无风险利率 rf），其余买风险组合——所有「无风险 + 风险资产」的组合在风险-收益图上是一条直线。与有效前沿相切的那条线（资本市场线）是最优的：切点组合 M 是所有投资者风险资产的最优选择——不管你风险偏好如何，差别只在于「M 和国债」的配比（保守多放国债、激进加杠杆买 M）。这就是两基金分离定理，也是指数基金存在的理论依据。

    5.4 CAPM：给风险定价

    既然人人都持有 M（市场组合），那么单个资产的风险溢价只取决于它对 M 的贡献——用 β 度量：

    E(Ri) = rf + βi·( E(Rm) − rf )， βi = Cov(Ri, Rm) / Var(Rm)β=1：与大盘同步；β>1：放大大盘（高弹性）；β=0.5：半速跟随。直觉：β 是「大盘动时它跟多紧」。

    CAPM 的结论很锋利：只有系统性风险（β）获得补偿；能被分散掉的特质风险不产生溢价——因为理性投资者都持分散组合，特质风险在组合内互相抵消，没人愿意为它付钱。

    🧮 算一算：基金经理到底有没有本事（α）

    无风险利率 3%，某基金 β = 1.2，去年大盘超额收益 6%，基金实际收益 12%。它跑赢了吗？

    1. CAPM 应得收益：3% + 1.2 × 6% = 10.2%
    2. 实际收益 12% > 10.2%
    3. α = 12% − 10.2% = 1.8%

    结论：基金涨 12% 不算本事——β=1.2 的组合「应该」涨 10.2%。多出来的 1.8% 才是管理能力（或运气）的候选证据。评估任何业绩都要先做 β 调整，这是看懂基金评价的第一课。

    5.5 多因子模型：CAPM 不够用了

    现实里小盘股长期跑赢大盘股、低估值（价值）股跑赢高估值股、动量效应存在——单一市场因子解释不了。Fama-French 三因子（市场 / 规模 SMB / 价值 HML）及后续五因子、动量因子，把收益分解为：

    Ri − rf = α + β市场·MKT + β规模·SMB + β价值·HML + ε回归跑出来：α 是真本事，各 β 是风格暴露，ε 是特质噪音。

    两大用途：风险归因（我的组合其实重仓了「小盘 + 价值」，风险到底在哪）与业绩归因（去年赚的钱是 α 还是恰好站在了价值风口）。买基金前先看它的因子暴露——这比看历史收益率靠谱得多。

    5.6 风险度量与估计陷阱

    • 波动率：对称惩罚涨跌，简单但不符合直觉（涨也算「风险」？）。
    • 下行波动 / VaR / ES：只关心亏损侧（VaR/ES 详见第 10 章）。
    • 最大回撤：从业者心里的真指标——「最深挖了多深的坑、多久爬出来」。
    ⚠️ 估计陷阱（实战中翻车最多的地方）① 资产多、样本短时，协方差矩阵是「噪声矩阵」：元素误差大、可能不正定，优化器会把误差放大成极端权重——用收缩估计（Ledoit-Wolf）或因子模型降维；② 期望收益的估计误差极大，优化器对它极其敏感（「误差最大化」现象）——用长期、稳健的先验约束；③ 相关性在危机中集体飙升，分散化在最需要时最弱——尾部分散要靠期权等非线性工具。

    第 6 章远期与期货定价

    前置要求：2.1、3.3–3.4 预计时长：5–6 小时 难度：★★☆ 配套阅读：Hull 第 2、3、5 章
    🎯 本章学习目标分清「远期价格」与「远期价值」；会用持有成本模型推导各种情形下的远期定价公式；理解保证金与逐日盯市；会用基差解释套期保值的效果与残差。

    6.1 先分清两个概念：远期价格 ≠ 远期价值

    远期价格 F₀：今天签约时，让合约价值为零的那个交割价（公平价）。远期价值 f：已经签下的旧合约，现在值多少钱（会随行情漂移）。签约瞬间价值为零；之后标的移动、时间流逝，价值开始变化——你赚的就是这个变化。混淆这两个概念是本章第一大坑。

    6.2 持有成本模型：一个套利故事推出来的公式

    问题：黄金现货 1800 美元，1 年期利率 3%（连续复利），1 年期远期应该报多少？用第 3 章的套路——两种「合成方式」必须同价：

    1. 方式 A：直接签远期，1 年后按 F 拿到黄金；
    2. 方式 B：今天借钱 1800 买现货，持有 1 年（黄金无利息、假设无存储费），还钱 1800·e0.03 = 1854.8。

    A 和 B 的期末结果完全一样（都拿到一盎司黄金），所以今天成本必须一样：F₀ = 1800·e0.03 = 1854.8。

    🧮 算一算：抓一个套利机会

    若市场上真的有人愿意按 1880 卖给你 1 年期远期（高于理论价 1854.8），怎么无风险赚钱？

    1. 借钱 1800 → 买现货黄金（方式 B 的组合）
    2. 同时按 1880 卖出 1 年期远期（承诺 1 年后交黄金）
    3. 1 年后：交出黄金收 1880，还贷款 1854.8
    4. 无风险利润 = 1880 − 1854.8 = 25.2 美元/盎司，今天一分钱不出

    现实中套利者会瞬间吃掉这 25 美元，把远期价压回 1854.8 附近。远期价格 = 现货 + 持有成本 − 持有收益，这就是持有成本模型的全部。

    各种情形总结（考试与实战速查）

    标的情形远期价格公式说明
    无收益资产（黄金，免存储费）F₀ = S₀·erT纯资金成本
    已知现金收入（现值 I）F₀ = (S₀ − I)·erT有分红 / 利息 → 抵减
    已知红利率 q（股指常用）F₀ = S₀·e(r−q)T股指期货贴水的主因之一
    商品（存储成本 u、便利收益 y）F₀ = S₀·e(r + u − y)T油价期货的升水 / 贴水由供需决定 y
    💡 记忆口诀持有资产多得到的（红利、便利收益）压低远期价；多付出的（利息、仓储）抬高远期价。判断任何情形，先问「拿现货比拿远期多了什么、少了什么」。

    6.3 已签合约值多少钱：远期价值算例

    🧮 算一算：三个月后我的远期合约值多少

    三个月前你按 K = 1854.8 签了 1 年期黄金远期多头。现在现货涨到 S = 1900，剩余期限 0.75 年，利率仍 3%。合约现值多少？

    1. 思路：远期多头 = 「到期付 K 拿到资产」= 持有资产（扣掉持有收益） − 现金 K 的现值
    2. 资产部分（黄金无收益）：1900 的现值化？直接用公式 f = S − K·e−rτ
    3. f = 1900 − 1854.8 × e−0.03×0.75 = 1900 − 1854.8 × 0.9778
    4. f ≈ 1900 − 1813.5 = 86.5 美元——当时价值为零的合约，现在浮盈 86.5

    对空头正好是 −86.5：远期是零和游戏。公式的另一读法：远期价值 = (当前远期价 − 签约交割价) 的现值，两种写法完全等价。

    6.4 期货：保证金、盯市与杠杆

    期货 = 远期 + 交易所机制。以国内商品期货常见 10% 保证金为例：名义 100 万的合约，交 10 万保证金即可交易——杠杆 10 倍，价格涨 3% 你赚 30%、跌 3% 亏 30%（保证金的三成）。每天收盘按结算价逐日盯市：赚的钱当天入账（可再投资），亏的钱当天扣除，跌破维持保证金就收到追加保证金通知（Margin Call），不补则强平。盯市是交易所敢于担保的底气，也是期货与远期价格略有差异的原因（利率与标的正相关时期货略高：盈利更早到账）。

    6.5 套期保值与基差：对冲不是 100% 完美

    🧮 算一算：农民的套期保值账本

    农民 6 月后收玉米，现货现价 3800 元/吨，他卖出 6 个月后到期的玉米期货，价格 3900。到期时现货价可能 3700 也可能 4100，结果如何？（假设到期基差为 0）

    1. 情形一（到期现货 3700）：现货卖 3700 + 期货空头赚 (3900−3700)=200 → 总收款 3900
    2. 情形二（到期现货 4100）：现货卖 4100 + 期货空头亏 (3900−4100)=−200 → 总收款 3900
    3. 无论涨跌，收入锁定在 3900——用价格不确定性换确定性，这就是对冲。

    现实中到期时现货与期货不完全收敛，基差 = 现货价 − 期货价会漂移，套保结果 = 锁定价 + 基差变化——这叫基差风险，是对冲后残留的风险。选对冲工具的三匹配：期限匹配、标的相关匹配、数量匹配（用 β 或久期调整手数）。

    第 7 章期权定价与希腊字母

    前置要求：第 2、6 章 预计时长：14–18 小时 难度：★★★（全书核心） 配套阅读：Hull 第 9、10、12–14、18、19 章
    🎯 本章学习目标（全书最重要的一章）熟练写出四个基本头寸的损益；会推导并使用买卖权平价；手算单期二叉树并理解风险中性定价；记住 Black-Scholes 公式并会代入计算；能用五个希腊字母描述和管理期权风险；理解隐含波动率与微笑的交易含义。

    7.1 期权是什么：四个基本头寸

    看涨期权（call）：付权利金，买「将来可以按行权价 K 买入」的权利。看跌期权（put）：买「可以按 K 卖出」的权利。注意用词：是「可以」不是「必须」——这是权利与义务的分界。设标的现价 100，行权价 K = 100，权利金各 5 元，到期时标的三种价位下的损益：

    头寸到期价 80到期价 100到期价 120最大亏损最大盈利
    买入看涨−5−5+15−5（权利金）无上限
    卖出看涨+5+5−15无上限+5（权利金）
    买入看跌+15−5−5−5（权利金）95（标的价值）
    卖出看跌−15+5+595+5（权利金）

    看懂这张表，期权的一半就懂了：买方盈亏不对称（亏有限、赚无限），卖方正好相反（赚有限、亏无限）。卖期权像开保险公司：稳定收保费，但必须留足资本金防大灾；买期权像买保险。多头的期望价值是负的（权利金里含保险费），但买的是凸性与安心。

    7.2 内在价值、时间价值与买卖权平价

    内在价值 = 立即行权能拿到多少（max(S−K, 0) 对 call）；时间价值 = 权利金 − 内在价值，买的是「未来行情的可能性」，随到期日临近而衰减。价内 / 价外 / 平值：行权是否划算的三种状态。

    买卖权平价（Put-Call Parity）——本章第一个必须烂熟的结论。构造两个组合（欧式、无红利、到期日相同）：

    • 组合甲：1 股股票 + 1 份看跌期权；
    • 组合乙：1 份看涨期权 + 现金 K·e−rT（存银行到期正好变 K）。

    到期时：若 ST > K，甲 = ST（看跌作废），乙 = 看涨行权得 ST − K 加现金 K = ST；若 ST < K，甲 = 行权看跌得 K，乙 = 看涨作废 + 现金 K。两个组合任何情形下都相等，所以今天也必须相等：

    C + K·e−rT = P + S ⟺ C − P = S − K·e−rT连续红利率 q 版本：C − P = S·e−qT − K·e−rT。平价关系一旦被打破，就是白捡钱的机会（套利者瞬间抹平）。
    🧮 算一算：用平价关系「抓漏洞」

    S = 100，K = 100，r = 3%，T = 1 年，无红利。市场看涨期权 C = 6 元，看跌期权 P = 3 元，有没有套利？

    1. 理论平价：C − P 应 = 100 − 100·e−0.03 = 100 − 97.04 = 2.96
    2. 市场实际：C − P = 6 − 3 = 3.00，比理论高 0.04 → 「C−P」组合被高估
    3. 套利：卖看涨 6 元、买看跌 3 元（净收 3 元），再买 1 股股票、借入 97.04 元
    4. 到期无论涨跌，组合正好轧平，锁定无风险利润 ≈ 0.04 元/股

    数字小是因为市场有效——但每年全球无数系统 24 小时盯着这类偏差。平价关系是检验期权报价是否自洽的第一道体检。

    ⚠️ 经典考点：美式看涨不该提前行权行权 = 放弃时间价值 + 交出现金 K 失去利息。卖掉期权（拿回权利金）永远不差于行权。所以无红利美式看涨的市场价 = 欧式价。但美式看跌可能提前行权：深度价内时，现金的利息收益超过了剩余时间价值。两者的不对称来自「现金利息的方向」。

    7.3 二叉树：把定价变成小学算术

    二叉树是理解一切期权定价的「显微镜」：假设一段时间后价格只有两种走向。看一个完整的手算例子：

    🧮 算一算：单期二叉树完整定价

    股票现价 100，一年后要么涨到 120（u = 1.2），要么跌到 80（d = 0.8）。看涨期权 K = 100，一年期利率 5%（单期，年复利）。期权今天值多少？

    方法一：复制法（无套利的本门功夫）

    1. 到期 payoff：涨时 Cu = 120−100 = 20；跌时 Cd = 0
    2. 用「Δ 股股票 + 借款 L」复制期权：两个状态的终值必须分别等于 20 和 0
    3. 涨：120Δ − 1.05L = 20；跌：80Δ − 1.05L = 0 → 两式相减：40Δ = 20 → Δ = 0.5 股
    4. 代回：80×0.5 − 1.05L = 0 → L = 38.10（今天借 38.10，到期还 40）
    5. 期权价格 = 复制成本 = 0.5×100 − 38.10 = 11.90 元

    方法二：风险中性法（殊途同归，且是蒙特卡洛的基础）

    1. 找一个概率 p 使股票期望收益 = 无风险利率：120p + 80(1−p) = 105 → p = 0.625
    2. 期权价格 = 该 p 下的期望 payoff 贴现：c = (0.625×20 + 0.375×0)/1.05 = 11.90 元 ✓

    三句总结：① 期权可以用股票 + 现金精确复制；② 复制成本即价格；③ 换个说法——存在一个「让所有资产都只赚无风险利率」的虚拟概率（风险中性概率 p），用它求期望再贴现就是价格。p = 0.625 与真实涨跌概率无关——它由 u、d、r 反推，是定价的记账工具。真实概率是 0.9 还是 0.6 都不影响期权价格，因为复制组合把不确定性完全消除了。

    多期树：把一年切成 n 段，每段 u、d 重复上述步骤，从树梢倒推回树根（每节点取贴现期望）。n→∞ 收敛到 Black-Scholes 公式。美式期权：每个节点比较「行权价值 vs 继续持有价值」取大者——树结构天生支持美式，这是它相对 BS 公式的优势。

    标准 CRR 参数（σ 来自第 2 章 GBM，保证树的波动率与真实一致）：

    u = eσ√Δt， d = 1/u， p = ( er·Δt − d ) / ( u − d )

    7.4 Black-Scholes 公式：行星的轨道方程

    把二叉树的时间步长切到无穷小，假设：无交易成本、利率与波动率恒定、价格服从 GBM（路径连续无跳空）、欧式、无红利——得到教科书上最著名的公式：

    c = S₀·N(d₁) − K·e−rT·N(d₂)， p = K·e−rT·N(−d₂) − S₀·N(−d₁)
    d₁ = [ ln(S₀/K) + (r + σ²/2)·T ] / (σ·√T)， d₂ = d₁ − σ·√TN(·) 为标准正态分布函数；φ(·) 为其密度。

    读懂它（比记住更重要）：

    • K·e−rT = 行权价的现值（到期才付 K，所以先贴现）；
    • N(d₂) ≈ 风险中性世界里「到期价内、会被行权」的概率；
    • S₀·N(d₁) ≈ 行权时拿到股票的风险中性期望现值，N(d₁) 同时是期权价格对标的一阶敏感度（Delta）；
    • 整体结构 = 「期望拿到的 − 期望付出的」，和二叉树公式一模一样，只是连续化了。
    🧮 算一算：完整代入一次 BS 公式

    S₀ = 100，K = 100，r = 3%，σ = 20%，T = 1 年。求看涨期权价格。

    1. d₁ = [ ln(1) + (0.03 + 0.02)×1 ] / (0.2×1) = 0.05/0.2 = 0.25
    2. d₂ = 0.25 − 0.2 = 0.05
    3. 查正态表：N(0.25) = 0.5987，N(0.05) = 0.5199
    4. c = 100×0.5987 − 100×e−0.03×0.5199 = 59.87 − 50.46
    5. c ≈ 9.41 元（本例平值期权价值约为标的价格的 9.4%）

    拿这一题去对照第 9 章的代码：解析解、蒙特卡洛、二叉树三条路算出来的都应是 9.41 附近——用解析解验证数值解，是量化工程师的日常仪式。

    ⚠️ 模型的局限（比公式本身更重要）真实市场有肥尾、跳空、随机波动率，BS 的假设并不成立。但它依然是行业标准语言：交易员用隐含波动率报价而非直接报价格，模型的错误被统一吸收进「波动率微笑」这个修正层（7.6）。学会公式只是开始，学会「模型哪里不可信」才是专业。

    7.5 希腊字母：期权的仪表盘

    期权价格对各种因素的敏感度各有一个希腊字母——这是交易台的日常语言：

    Δ Delta = ∂c/∂S（价格敏感度）：看涨 = N(d₁)，看跌 = N(d₁) − 1
    Γ Gamma = ∂²c/∂S² = φ(d₁)/(S₀σ√T)（Delta 本身的变化速度）
    Vega = ∂c/∂σ = S₀·φ(d₁)·√T（对波动率的敏感度）
    Θ Theta = ∂c/∂t（时间流逝的价值损耗，通常为负）
    ρ Rho = ∂c/∂r = K·T·e−rT·N(d₂)（对利率的敏感度，通常最小）
    字母回答的问题做多的期权 =怎么管理
    Delta标的动 1 元，我动多少？持有 N(d₁) 份标的用标的/期货对冲到中性
    Gamma标的动起来，我的 Delta 变多快？做多 Gamma（波动越大越有利）定期再平衡；Gamma 是对冲的「摩擦成本」
    Vega波动率涨 1 个点，我赚/亏多少？做多 Vega买卖其他期权调整净敞口
    Theta今天什么都没发生，我赚/亏多少？付 Theta（每天流血）Theta 是 Gamma 的「保费」：多 Gamma 必多负 Theta
    Rho利率动 1%，我动多少？做多 Rho（看涨）长期限期权才显著，短线可忽略
    🧮 算一算：Delta 对冲为什么不完美（Gamma 的代价）

    交易台卖出 1000 股对应单位的平值看涨（用 7.4 的参数：Delta = N(0.25) ≈ 0.599，Gamma ≈ 0.0193）。如何对冲？标的涨 2 元后发生了什么？

    1. 对冲：买 0.599×1000 = 599 股（Delta 中性：标的涨 1 元，期权亏 ≈ 股票赚，互相抵消）
    2. 标的真的涨 2 元 → 每股期权亏损 ≈ 0.599×2 + ½×0.0193×2² = 1.198 + 0.039 = 1.237 → 总亏 1237
    3. 股票端盈利：599×2 = 1198
    4. 净结果：−39 元——一阶全对冲了，剩下的是二阶（Gamma）损耗

    结论：Delta 对冲后不是「没事了」，而是暴露了 Gamma——标的跳动越大，再平衡前的损耗越大。做市商的日常：不断再平衡压 Gamma，每次再平衡都有交易成本；赚的权利金能否盖过成本，取决于定价时收的波动率是否高于实际波动。期权生意的本质 = 波动率的买卖。

    7.6 波动率：唯一看不见的输入

    • 历史波动率：过去收益率的标准差（年化）。用 EWMA / GARCH 可以给近期数据更大权重（捕捉「波动聚集」）。
    • 隐含波动率（IV）：让 BS 价格 = 市场价格反解出的 σ。它是市场对未来波动的共识预期 + 风险溢价，是期权市场真正的「价格」。
    • 波动率微笑 / 偏斜：同一到期日、不同行权价的 IV 不同。股指期权呈「偏斜」：低行权价（虚值 put）IV 显著更高——市场愿意为崩盘保险付高价，因为真实分布左尾比对数正态肥得多。外汇期权常是对称微笑。
    • 期限结构：IV 随到期日变化，财报、议息等事件会在短期限上顶出尖峰。
    • VIX：标普 500 期权 IV 的加权指数（恐慌指数），国内对应中证 500 期权波动率指数等。
    💡 专业视角的转变新手看期权价格，专业人士看 IV：同一个标的、不同行权价的期权，报的是一组 IV 曲线。判断「这个期权贵不贵」，实际是判断「这个 IV 相对历史与自身波动，高了吗」。期权交易 = 在交易波动率，标的方向只是其中一维。

    7.7 三个入门策略（把知识连起来）

    • 保护性看跌（买股 + 买 put）：给持仓买保险——下跌由 put 兜底，上涨全部保留。成本 = 权利金（保险费）。对应 7.2 组合甲。
    • 备兑开仓（买股 + 卖 call）：持股收权利金增厚收益，代价是上涨收益被封顶。适合温和看涨 / 震荡市。对应「卖出看跌」的等价头寸（平价关系！）。
    • 买入跨式（买 call + 买同价 put）：赌「大波动」，方向无所谓——财报、议息前常用。成本高（双份权利金），需要波动真的大于 IV 才赚钱。

    风险中性概率 p 和真实上涨概率无关，为什么定价仍然正确？
    因为定价基于复制而非预测：Δ 股 + 现金的组合已完全复制期权在任何状态下的 payoff，其成本是唯一无套利价格，复制关系不依赖任何概率。p 只是让「股票期望收益 = r」成立的记账概率（等价鞅测度）。真实概率影响你「买不买」（投机观点），不影响「值多少」（公允价格）。
    卖出跨式（卖 call + 卖同价 put）的希腊字母敞口？赚什么、怕什么？
    Delta 近似中性，空 Gamma、空 Vega、多 Theta：赚横盘时的时间价值；怕价格大幅跳动（负 Gamma）与隐含波动率上升（负 Vega）。本质是卖保险：高胜率、低赔付频率、单次大额风险，必须配合限额与尾部对冲。
    为什么无红利美式看涨不该提前行权，而美式看跌可能？
    看涨：行权 = 放弃时间价值，且要立刻付出 K 损失利息；卖掉期权拿回的钱 ≥ 行权所得，永远不亏。看跌：行权 = 收到现金 K 开始生息；深度价内时利息收益可能超过剩余时间价值，因此提前行权可能更优。不对称的根源是「现金在手的方向」。
    股指期权的隐含波动率曲线为什么左偏（低行权价 IV 更高）？
    真实市场崩盘时呈负偏、肥尾，且波动率与下跌同步放大（杠杆效应）。虚值 put 恰好在崩盘中赔付，是尾部保险，需求旺盛推高其 IV。BS 的对数正态假设低估左尾，误差就体现在偏斜上——偏斜曲线是市场对「模型哪里错了」的集体定价。

    第 8 章随机过程深化与利率模型

    前置要求：第 2、7 章 预计时长：10–12 小时 难度：★★★ 配套阅读：Hull 第 13 章；Shreve II（选读）

    8.1 二次变差：½ 项的真正来源

    把 [0, T] 切成 n 小段，把布朗运动每段增量平方后加总：∑(ΔW)²。确定性函数（如直线）的这个和趋于 0；但布朗运动的这个和依概率收敛到 T——不趋于零！这叫二次变差。

    直觉：布朗路径放大看永远锯齿，每小段都在「抖」，抖动的平方累积起来是实打实的量。推论：对随机价格做泰勒展开时，二阶项 (dW)² 量级 = dt，不能丢——这就是伊藤引理 ½σ²S²f″ 项的来历，也是「期权有 Gamma 就有 Gamma 收益」的数学根基（做市商靠它吃饭）。

    8.2 伊藤引理三步使用法（练到条件反射）

    1. 写普通链式法则：df = f′(S)·dS + f′(t)·dt
    2. 加伊藤修正项：+ ½·f″(S)·σ²S²·dt（来自 (dW)² = dt）
    3. 代入 dS = μS·dt + σS·dW 并整理（dt 归 dt，dW 归 dW）。
    🧮 算一算：两个必会例题

    ① f(S) = ln S：f′ = 1/S，f″ = −1/S²
    d(ln S) = (1/S)(μS·dt + σS·dW) + ½(−1/S²)σ²S²·dt = (μ − σ²/2)·dt + σ·dW
    ——这就是 GBM 的解 ST = S₀exp[(μ−σ²/2)T + σ√T·Z] 的来源，「波动率拖累」−σ²/2 明明白白。

    ② f(S) = S²（第 2 章算过）：d(S²) = (2μ + σ²)S²·dt + 2σS²·dW。
    两个例子的共同点：修正项都来自 ½f″σ²S²。会这两个，定价里 90% 的伊藤计算就够用了。

    8.3 风险中性测度：P 和 Q 是两个世界

    第 7 章二叉树里已经见过风险中性概率。现在把它说透：

    • 同一个随机世界，可以配不同的「概率外衣」。真实世界 P：股票平均每年赚 μ（有风险溢价）。虚拟世界 Q：通过重新分配概率权重（Girsanov 定理），让每只资产贴现后的价格变成鞅——即所有资产的期望收益都等于无风险利率 r。过程：从 P 换到 Q，只改漂移（μ→r），波动率不变。
    • 定价公式（全学科的顶点）：Vt = e−r(T−t)·EQ[ payoff | Ft ]——在 Q 世界里求期望，再按无风险利率贴现。
    • 为什么不直接用 P 求期望？因为 P 下的期望收益 μ 不可观测、估计误差巨大；而 Q 是由当前市场价格反推出来的（无套利保证唯一），定价只需要 Q。风险溢价问题被「换测度」这个操作干净地绕开了——这正是无套利定价的深刻之处。
    💡 建模顺序（工程实务）实务中常反过来做：直接在 Q 世界里写模型（比如股票 = GBM，波动率取隐含波动率），校准到当前市场价格，然后模拟求期望贴现。真实测度 P 只在策略研究 / 风险预测时才需要。初学时记住：定价在 Q，预测在 P，两个世界别混。

    进阶词汇表（混个眼熟即可）：Girsanov 定理 = 换测度的数学操作；计价单位（numeraire）= 「用什么资产当记账单位」，换计价单位对应换测度；T 远期测度 = 以 T 期零息债记账，利率产品定价最方便。这些在 Shreve II 里是主线，本手册不展开。

    8.4 利率模型三大家族

    利率和股价不同：它有均值回复（央行不会让利率涨到天上去）、水平有约束、且有整条曲线要建模。三类模型对应三种思路：

    Vasicek：dr = a·(b − r)·dt + σ·dW （回复速度 a、长期均值 b；可为负利率）
    CIR：dr = a·(b − r)·dt + σ·√r·dW （扩散项 √r 保证 r ≥ 0）
    模型思路优点缺点
    Vasicek / CIR（均衡类）从经济假设直接刻画短期利率有解析解（仿射期限结构），好校准、好理解拟合当前曲线不精确；参数未必贴合市场
    HJM（无套利类）直接建模整条远期利率曲线的演化精确拟合当前曲线，理论最一般一般无解析解，实现复杂
    LMM / BGMHJM 的对数正态实现，建模市场远期利率与 cap/floor 市场报价直接对接，交易台标准计算量大

    选型逻辑：要快速得到带解析解的模型（研究、教学、粗算）→ Vasicek/CIR；要给利率衍生品精确定价（实务）→ HJM/LMM。它们都属于「仿射期限结构」或其推广——零息债价格是短期利率的指数仿射函数，这一结构是解析可解性的关键。

    「贴现后的资产价格在风险中性测度下是鞅」——这句话如何变成定价公式？
    鞅 = 未来条件期望等于当前值。于是任何衍生品都可写成：价格 = e−r(T−t) × payoff 在 Q 下的条件期望。BS 公式、二叉树、蒙特卡洛（模拟 Q 下的路径求平均 payoff）都是这条公式的三种实现。
    Vasicek 的什么缺陷被 CIR 解决了？各自代价是什么？
    Vasicek 的扩散项恒定，利率可为负且波动不随水平变化。CIR 在扩散项加 √r：利率接近 0 时波动趋零、无法穿越 0，保证非负。代价：解析式更复杂、校准更难，且强制的零下界在负利率时代反而脱离现实（欧洲、日本出现过负利率）。
    为什么实务定价「直接在 Q 世界里建模」是可行的？它依赖什么保证？
    因为定价只需要 Q 下的分布与当前市场价格一致（校准），不需要 Q = 真实世界。无套利保证：若 Q 世界定价与市场一致，则复制与对冲成立。这正是「相对定价」的工程化：把「世界真实怎么走」与「价格今天该多少」解耦。

    二叉树 / 三叉树美式期权（提前行权）、直观高维爆炸、收敛有锯齿美式put、可转债、实物期权
    蒙特卡洛高维、路径依赖（亚式/障碍/雪球）慢（误差 1/√N）、美式需特殊处理多资产篮子、奇异期权、风险模拟
    有限差分（PDE）低维美式、边界条件灵活高维难、实现细节多美式期权、障碍期权

    记忆法：美式找树和差分，高维和路径找蒙特卡洛，有解析解就先写解析解。

    9.2 树方法要点

    第 7 章已经手算过单期树。多期实现两件事：① 从树梢 payoff 出发倒推（贴现期望）；② 美式期权在每个节点比较「立即行权 vs 继续持有」取大者。工程细节：CRR 参数（u = eσ√Δt）保证树与 GBM 的波动率匹配；收敛价格随步数呈锯齿振荡（离散化误差），可用奇偶步数平均或 Richardson 外推平滑。三叉树收敛更稳，是利率模型（Hull 第 31 章思路）的标配。

    9.3 蒙特卡洛：用随机性驯服随机性

    原理直觉：想算不规则形状的面积？往正方形里随机撒豆子，数落在形状里的比例。想在 Q 世界算期望 payoff？随机模拟一万条价格路径，算每条的 payoff，取平均、贴现——大数定律保证平均值收敛到期望。用「撒豆子估 π」练一次手是理解 MC 的最好方式。

    ⚠️ 误差结构：1/√N 是宿命蒙特卡洛的标准误差 ∝ 1/√N。想要精度提高 10 倍 → 路径数要乘 100。例：10 万条路径误差约 0.07 元，想要 0.007 元就要 1000 万条。所以方差缩减不是优化技巧，是必需品：
    • 对偶变量：每对随机数 Z 和 −Z 同时模拟（一个涨一个跌），取平均——漂移噪音相互抵消，方差大降。
    • 控制变量：用「已知解析解的量」（如 GE 的到期期望 E[S_T]）校正模拟偏差：MC结果 − 模拟出的已知期望 + 真实已知期望。
    • 重要性抽样 / 分层：把随机样本集中到对 payoff 最重要的区域（比如深价外的尾部），别浪费算力在不重要的区域。

    美式期权 + 蒙特卡洛的组合是学术难题（未来价值未知），工程解法是 Longstaff-Schwartz 最小二乘回归（LSM）：用回归近似「继续持有的价值」。知道有这回事即可，进阶再学。

    9.4 有限差分：把 BS 方程变成网格

    把 BS 偏微分方程写在「价格 × 时间」网格上，导数用相邻格点差分近似，从到期边界倒推回今天。三种格式一句话：

    • 显式：直接算，快，但时间步长受限（不稳定会数值爆炸）——学习用；
    • 隐式：每步解一个线性方程组，无条件稳定——生产可用；
    • Crank-Nicolson：两者加权，精度最高，需配合 Rannacher 平滑处理不连续。

    低维美式、障碍类期权它很顺手；三维以上就轮到蒙特卡洛出场。

    9.5 三个模板：直接可跑的定价代码

    三个方法各一份，标的、参数完全一致（S=100, K=100, r=3%, σ=20%, T=1）——跑完后互相核对，都应得到 ≈ 9.41：

    # ① Black-Scholes 解析解 —— 永远先用解析解当「标准答案」
from math import log, sqrt, exp
from scipy.stats import norm          # norm.cdf = 标准正态分布函数 N(·)

def bs_call(S, K, r, sigma, T):
    d1 = (log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*sqrt(T))
    d2 = d1 - sigma*sqrt(T)
    return S*norm.cdf(d1) - K*exp(-r*T)*norm.cdf(d2)

print(bs_call(S=100, K=100, r=0.03, sigma=0.2, T=1.0))   # 9.41
    # ② 蒙特卡洛 —— 直接模拟第 8 章风险中性测度下的 GBM 解
import numpy as np

def mc_call(S0, K, r, sigma, T, n_paths=200_000, seed=42):
    rng = np.random.default_rng(seed)                  # 固定种子 → 结果可复现
    z = rng.standard_normal(n_paths)                   # Q 世界里的随机冲击 Z~N(0,1)
    # GBM 的解：S_T = S0 * exp((r - σ²/2)T + σ√T·Z)   —— 注意 -σ²/2「波动率拖累」
    ST = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*z)
    payoff = np.maximum(ST - K, 0.0)                   # 到期 payoff（向量化，无循环）
    disc = np.exp(-r*T)                                # 风险中性贴现
    price = disc * payoff.mean()                       # 期望 payoff 的现值
    se = disc * payoff.std(ddof=1) / np.sqrt(n_paths)  # 标准误差（~1/√N）
    return price, se

print(mc_call(S0=100, K=100, r=0.03, sigma=0.2, T=1.0))  # ≈ (9.41, 0.07)
    # ③ CRR 二叉树 —— 支持欧式 / 美式，理解「倒推 + 提前行权」
import numpy as np

def crr_option(S0, K, r, sigma, T, n=200, kind='call', american=True):
    dt = T / n
    u, d = np.exp(sigma*np.sqrt(dt)), np.exp(-sigma*np.sqrt(dt))  # CRR 参数
    p = (np.exp(r*dt) - d) / (u - d)                   # 风险中性概率
    disc = np.exp(-r*dt)
    j = np.arange(n+1)
    ST = S0 * u**(n-j) * d**j                          # 到期时刻所有可能价格
    V = np.maximum(ST - K, 0.0) if kind == 'call' else np.maximum(K - ST, 0.0)
    for i in range(n-1, -1, -1):                       # 从树梢倒推回树根
        V = disc * (p*V[:-1] + (1-p)*V[1:])            # 贴现期望
        if american:                                   # 美式：比较立即行权
            S = S0 * u**(i-np.arange(i+1)) * d**np.arange(i+1)
            ex = np.maximum(S - K, 0.0) if kind == 'call' else np.maximum(K - S, 0.0)
            V = np.maximum(V, ex)
    return V[0]

print(crr_option(100, 100, 0.03, 0.2, 1.0))              # ≈ 9.41（欧式 call）
print(crr_option(100, 100, 0.03, 0.2, 1.0, kind='put'))  # 美式 put > 欧式 put

    10.1 市场风险：VaR 与 ES

    VaR（在险价值）：在置信水平 α、持有期 Δt 内，最大的「平常」损失。它是风险管理的通用语言：「95%/1 天 VaR = 300 万」= 正常日子里，100 天里有 95 天单日亏损不超过 300 万（剩下 5 天会超过，但不知道超多少）。

    VaRα ≈ V · zα · σ · √Δt （正态近似；z0.95≈1.65，z0.99≈2.33）V 为组合价值，σ 为日波动率。

    1 亿元组合，日波动率 1.5%，99% 置信、1 天持有期。

    1. VaR = 1 亿 × 2.33 × 1.5%
    2. ≈ 350 万元——即「最正常的 99% 的日子里，单日亏损不会超过 350 万」
    3. 10 天持有期：乘 √10 ≈ 3.16 → 约 1105 万（再次见到 √T！）

    方法做法优点缺点
    历史模拟重放过去 N 天的真实损益，取分位数无分布假设、含真实肥尾「过去代表未来」，对窗口敏感
    方差-协方差正态近似（上面的公式）快、易分解到头寸低估尾部（肥尾被正态抹平）

    VaR 的天生缺陷：不告诉你「超了之后亏多少」。一次亏 351 万和一次亏 3000 万，VaR 完全一样。ES（预期损失）补上：ES = 超过 VaR 的那些日子里的平均损失，对尾部更诚实，且满足一致性公理（分散化后风险不增），巴塞尔新规（FRTB）已用 ES 替代 VaR。

    算完还要「验货」：① 回测——统计实际亏损突破 VaR 的天数是否符合置信水平（99% VaR 若一年突破 20 次，模型明显失真）；② 压力测试——直接问「2008 / 2015 股灾 / 2020 疫情那天，我会亏多少」，把历史极端情景套进当前持仓。VaR 管「平常日子」，压力测试管「不平常的日子」，两者缺一不可。

    10.2 限额与对冲：把风险关进笼子

    交易台的风险控制 = 希腊字母限额 + 情景限额：Delta 限额管方向敞口、Gamma 限额管跳动风险、Vega 限额管波动率敞口；Theta 是收入来源（卖波动率的「工资」）。动态对冲的成本账：再平衡越频繁，Gamma 风险越小、交易成本越高——成本与风险的平衡点是做市商定价的核心。尾部对冲：用少量预算持续买入深度虚值 put 或做多波动率，为「肥尾日」买保险——平时天天小亏，崩盘日一次大赚，它是组合的「降落伞」。

    VaR 只给分位点，不管分位点之外亏多少；非次可加（合并组合 VaR 可能变大，违背分散化直觉）；对厚尾不敏感。ES = 超越 VaR 后的条件平均损失，刻画极端情形的严重程度，满足一致性（次可加），因此被 FRTB 采用。实务中两者搭配：VaR 做日常限额语言，ES 做尾部资本计量。
    一个回测年化 30%、夏普 3 的策略，你的第一步检查清单是什么？
    按顺序：① 前视偏差（信号用到未来信息了吗？财报公布日 vs 报告期）；② 成本真实吗（价差、冲击、换手）；③ 过拟合（参数敏感性、样本外表现）；④ 幸存者偏差（池子含退市股票吗）；⑤ 收益是否集中在极少数交易（统计显著性不足）；⑥ 是否有幸存的大额仓位依赖流动性假设。高夏普回测几乎总能查出以上至少一条。
    为什么「卖期权」策略长期像稳定赚钱，却可能一次亏光？如何管理？
    卖期权 = 收 Theta、扛尾部：多数时间赚时间价值（高胜率），但空 Gamma / 空 Vega 意味着崩盘日亏损可能吞掉数年利润（「压路机前捡钢镚」）。管理：仓位控制（凯利准则打对折再打对折）、限额与硬止损、买入尾部保险（虚值 put / 波动率多头）、压力测试定生死、随时确认保证金能扛住极端行情。

    附录 C术语表与常见问答

    性质：随查随用 建议：遇到生词先来这里

    C.1 术语速查表

    基础与市场

    现值 / 贴现（PV / Discounting）
    把未来的钱按利率折算成今天的价值：乘 e−rT（连续复利）。
    连续复利
    利息瞬间滚存的极限情形，终值 erT，金融定价的通用口径。
    无套利（No-arbitrage）
    市场不允许「零成本、零风险、正收益」；定价公式的推导基石。
    复制（Replication）
    用已有价格资产构造与目标产品现金流完全相同的组合，成本即价格。
    相对定价
    由已知价格推未知价格（无套利路线），不预测涨跌。
    对冲（Hedging）
    用反向头寸抵消已有风险敞口。
    保证金（Margin）
    交易期货 / 卖出期权时缴纳的履约担保金；杠杆 = 1/保证金比例。
    逐日盯市（Mark-to-market）
    每日按结算价结算盈亏的期货制度。
    基差（Basis）
    现货价 − 期货价；套期保值的残留风险来源。
    中央对手方（CCP）
    清算所插在买卖双方之间成为所有人的对手，集中管理违约风险。
    OTC（场外市场）
    双边定制的交易市场，灵活但承担对手方信用风险。
    流动性（Liquidity）
    快速、低成本成交的能力；买卖价差是其常用度量。

    固定收益

    到期收益率（YTM）
    使债券价格等于全部现金流现值的贴现率，即「买到到期的年化收益」。
    即期利率 s(t)
    从今天到 t 期的零息年化利率。
    远期利率 f(t₁,t₂)
    今天即可锁定的未来区间利率，由即期利率无套利推出。
    期限结构 / 收益率曲线
    利率随期限的变化曲线；倒挂常被解读为衰退信号。
    麦考利久期
    现金流现值加权的平均回款时间（年）。
    修正久期
    价格对利率的弹性：ΔP/P ≈ −D*·Δy。
    凸性（Convexity）
    价格-收益率关系的二阶修正；永远为正贡献。
    免疫（Immunization）
    资产与负债久期匹配，使净头寸对利率平行移动一阶不敏感。
    利率互换（IRS）
    固定与浮动现金流交换；互换利率 = 使初始价值为零的固定票息。
    浮动利率票据（FRN）
    票息随基准利率重置的债券；重置日价格回到面值。

    投资组合

    波动率（Volatility）
    收益率标准差；年化 = 日波动率 × √252。
    协方差矩阵（Σ）
    多资产两两协方差的矩阵；组合风险 wᵀΣw 的原料。
    有效前沿
    每个收益水平下方差最小的组合集合。
    最小方差组合
    有效前沿最左端（风险最小）的组合。
    资本市场线 / 两基金分离
    无风险资产与切点组合的连线；所有投资者只在这两个「基金」间配比。
    β（Beta）
    资产对市场组合的敏感度 = Cov/Var；系统性风险的度量。
    α（Alpha）
    实际收益超出风险模型（如 CAPM）预测的部分；「真本事」的候选证据。
    因子模型
    把收益分解为共同因子暴露 + 特质项的统计模型（Fama-French 等）。
    收缩估计（Shrinkage）
    把样本协方差向简单结构「拉」以降低估计误差（Ledoit-Wolf）。
    最大回撤（MDD）
    净值从历史最高点最深跌幅；从业者最看重的路径风险指标。

    期权与随机过程

    看涨 / 看跌期权（Call / Put）
    买入未来按 K 交易的权利（非义务）；call 赌涨，put 赌跌 / 保险。
    价内 / 平值 / 价外（ITM / ATM / OTM）
    立即行权赚钱 / 不赚不亏 / 不划算的三种状态。
    内在价值 / 时间价值
    立即行权所得；权利金减内在价值（为「可能性」付的钱）。
    买卖权平价（Put-Call Parity）
    C − P = S − Ke−rT；由复制推出的恒等式。
    欧式 / 美式期权
    到期才能行权 / 随时可行权。美式看涨（无红利）不应提前行权。
    隐含波动率（IV）
    使 BS 价格等于市场价的 σ；期权市场真正的「价格」。
    波动率微笑 / 偏斜
    IV 随行权价的变化曲线；股指左偏 = 崩盘保险更贵。
    Delta / Gamma / Vega / Theta / Rho
    价格对标的一阶敏感度 / Delta 的变化率 / 对波动率 / 对时间 / 对利率的敏感度。
    Delta 中性 / 动态对冲
    用标的抵消方向敞口；随行情变化持续再平衡。
    布朗运动（Wt）
    连续、独立增量、增量正态的随机过程；价格随机性的原子。
    几何布朗运动（GBM）
    dS = μS·dt + σS·dW；股票价格的标准模型。
    伊藤引理
    随机版链式法则，多出 ½σ²S²f″ 项；定价推导的引擎。
    二次变差
    布朗运动增量平方和收敛于 T；(dW)² = dt 的正式说法。
    风险中性测度 / 概率（Q / p）
    使所有资产期望收益 = 无风险利率的虚拟概率；定价用它，预测用真实测度 P。
    鞅（Martingale）
    未来条件期望等于当前值的过程；「公平游戏」的数学化。
    障碍 / 亚式期权
    敲入敲出（触价生效失效）/ 按均价结算的奇异期权。

    数值与风险

    蒙特卡洛（MC）
    随机模拟路径求期望 payoff 贴现；高维之王，误差 1/√N。
    方差缩减
    对偶变量、控制变量、重要性抽样等降低 MC 误差的技术。
    有限差分（FD）
    把 BS 偏微分方程在网格上离散求解；显式 / 隐式 / Crank-Nicolson。
    CRR 二叉树
    u=eσ√Δt、d=1/u 的标准二叉树；美式期权友好。
    校准（Calibration）
    用市场价格反推模型参数（如隐含波动率）。
    VaR（在险价值）
    给定置信水平的最大「平常」损失；三种算法：历史 / 方差-协方差 / 蒙特卡洛。
    ES（预期损失）
    超过 VaR 部分的条件平均损失；一致性风险度量，监管新标准。
    压力测试
    把历史极端情景套进当前持仓，回答「最坏那天亏多少」。
    回测（Backtest）
    用历史数据模拟策略表现；使命是「杀死」坏策略。
    前视偏差 / 幸存者偏差 / 过拟合
    回测三大杀手：用了未来信息 / 池子漏了死掉的公司 / 参数调过头。
    夏普比率（Sharpe）
    (收益 − 无风险利率) / 波动率；风险调整后收益的通用刻度。
    卡玛比率（Calmar）
    年化收益 / 最大回撤。

    C.2 学习过程中的常见疑难（知其所以然）

    为什么波动率按 √T 放大，而不是按 T？
    方差才与时间成正比（独立增量相加，方差可加）：2 年的方差 = 2 × 1 年方差。标准差是方差的平方根，所以按 √T 放大。推论：4 年的「1 倍标准差区间」宽度只有 2 年的 √2 倍——「长期持有风险更小」的部分直觉正来自此（相对波动下降）。
    「测度」到底是什么？用大白话解释。
    测度就是给可能世界分配权重的一套方式。同一批「未来的路径」，真实世界 P 的权重 = 真实发生概率；风险中性世界 Q 把权重重新分配（涨的调轻、跌的调重），使得「按这套权重算的期望收益」恰好等于无风险利率。路径集合没变、波动率没变，变的只是权重——于是定价（求期望）时用 Q，就不用再操心风险溢价是多少了。
    利率只有 3%，BS 公式里凭什么多出 σ²/2 = 2% 这么多？
    那是「波动率拖累」：先涨 50% 再跌 33% 回到原点，平均涨 8.5% 但复合收益是 0——波动本身侵蚀复合增长。在 Q 世界里要求 E[S_T] = S₀e^{rT}， therefore 对数漂移必须写 r − σ²/2。这也是「波动率本身有价值」的体现：期权多头恰恰从波动中赚 Gamma 收益。
    为什么Delta 对冲不能一步到位，要一直再平衡？
    因为 Delta 本身随标的价格变化（这就是 Gamma）。标的一动，中性就被打破，暴露新的方向风险；再平衡恢复中性，又产生交易成本。多空双方都在这条「Gamma 收益 vs 对冲成本」的跷跷板上，做市商的报价差就是给这道摩擦定价。
    蒙特卡洛明明是「随机」的，凭什么结果是可信的？
    大数定律：独立样本均值收敛到真期望，误差随 √N 可预测地缩小（标准误可估计！）。更妙的是我们可以量化不确定性：报「9.41 ± 0.07」而非只报一个数。可信的前提是随机数质量、路径模型正确（在 Q 世界）与方差控制。
    学完本手册，怎么判断自己「入门」了？
    三道硬标准（对应附录 A 三关卡）：① 能白纸推导平价关系并解释每个假设；② 能手算单期二叉树两种方法并解释风险中性概率；③ 能 20 分钟写出新 payoff 的蒙特卡洛代码并用解析解验证。加一道软标准：能把任何一款结构化产品拆成标准零件并说出风险所在。
    理论和市场天天不一致，学模型还有什么用？
    模型不是世界的照片，是世界的地图：它给你统一的语言（波动率、希腊字母）、定价的基准（错了多少、为什么错）与风险的坐标系。所有模型都错，有些有用（All models are wrong, some are useful）——专业的标志是知道手里这张地图哪里不可信。
    笔记越攒越多，怎么避免「记了从不看」？
    用本手册自带的工作流：❓疑问必须带「卡在哪一步」的具体描述（而不是「不懂」）；每周日固定 20 分钟清疑问（解决的就改写成 ✎ 心得，用自己的话）；每章「已学完」前，把 ⭐ 重点读一遍——笔记的价值在闭环，不在数量。
